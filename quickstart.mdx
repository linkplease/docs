---
title: "Quickstart"
description: "Send your first WhatsApp template through MetaSmart."
---

## 1. Create an API key

Open **MetaSmart → Developer API**, create a key, and enable **Send messages**. Copy the key immediately; MetaSmart only displays it once.

## 2. Choose an approved template

List the approved templates available to your key:

```bash
curl https://prod.api.metasmart.io/public/v1/templates \
  --header "X-API-Key: $METASMART_API_KEY"
```

Use the returned `id` as `template_id`. Supply exactly `variable_count` values in `{{1}}`, `{{2}}`, and subsequent numbered order.

## 3. Send the request

```bash
curl https://prod.api.metasmart.io/public/v1/messages/template \
  --request POST \
  --header "X-API-Key: $METASMART_API_KEY" \
  --header "Content-Type: application/json" \
  --data '{
    "phone": "+919876543210",
    "template_id": "66f17ef3bc9f9d23d0561a91",
    "variables": ["Ayush", "4:30 PM"]
  }'
```

A successful request returns `201 Created` with the MetaSmart conversation and message details.

```json
{
  "conversation_id": "66f18066bc9f9d23d0561ab2",
  "message": {
    "id": "66f18066bc9f9d23d0561ab3",
    "platform": "whatsapp",
    "direction": "out",
    "type": "template",
    "body": "Hi Ayush, your appointment is at 4:30 PM.",
    "template_name": "appointment_reminder",
    "status": "sent",
    "created_at": "2026-09-28T10:30:00Z"
  }
}
```

<Tip>
  Store API keys in a secret manager or server environment variable. Never place one in browser code or a mobile application.
</Tip>
